# Student Expense Tracker 🎓💰

A full-stack student expense tracker featuring visual analytics, budget forecasting tools, receipt OCR scanning, and cloud backup.

## Key Features
1. **User Authentication**: Sign Up, Login, Forgot Password, and Demo Account switcher.
2. **Dashboard**: Live Current Balance, Total Income, Total Expenses, Savings, and Budget remaining status.
3. **Receipt Upload with AI OCR**: Upload physical bill photos to auto-fill title, amount, category, date, and notes using Gemini Vision.
4. **Visual Analytics**: Interactive Recharts Pie Charts (Category Breakdown), Bar Charts (Monthly Spending), and Line Graphs (Daily Velocity).
5. **Budget Forecasting Tool**: AI velocity projections for month-end expenditure and daily safe spending caps.
6. **Expense History & Filters**: Search by keyword, date range, category, or payment mode (UPI, Cash, Card).
7. **Savings Goals & Gamification**: Target funds with milestone badges and confetti celebrations.
8. **Roommate Bill Splitter**: Calculate and track shared hostel/roommate bills.
9. **College Fee Payment Calendar**: Track tuition fee deadlines, hostel rent, and scholarship credits.
10. **Cloud Backup & Export**: Encrypted cloud server backup, CSV exports, and printable PDF statements.
11. **Penny AI Financial Advisor**: Conversational advisor for student budgeting questions.

## Running the Project
```bash
# Start development server (Node + Express + Vite)
npm run dev

# Production Build
npm run build
npm start
```
